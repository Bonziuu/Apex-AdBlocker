# Logo Apex AdBlocker

Materiały marki – **nie trafiają do paczki rozszerzenia**. Generowane razem z ikonami: `npm run icons` (źródło: `tools/build-icons.mjs`, funkcja `logoSvg`).

| Plik | Do czego |
|---|---|
| `apex-logo.svg` | logo wektorowe – dowolny rozmiar, strona, materiały |
| `apex-logo-1024.png`, `apex-logo-512.png` | logo w wysokiej rozdzielczości, przezroczyste tło |
| `apex-store-icon-128.png` | ikona do Chrome Web Store: 96 px znaku + 16 px przezroczystego marginesu (wytyczne sklepu) |
| `apex-logo-marquee-1024.png`, `apex-logo-marquee-560.png` | kwadratowe logo w stylu dużej grafiki promocyjnej (tło z gradientem), np. awatar GitHuba lub social media; 560 px to rozmiar oryginalny, 1024 px – powiększenie |

Logo to sam znak „Apex A” – bez badge'a stanu (✓ / pauza), który jest tylko w ikonach na pasku Chrome.
