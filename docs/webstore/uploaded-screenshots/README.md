# Materiały dostarczone przez autora

Po 5 PNG RGB 1280×800 dla PL i EN, przejrzane wizualnie. Oryginały zachowano
bez modyfikacji. To materiały marketingowe dostarczone przez autora, bez
potwierdzonego powiązania z hashem aktualnej paczki. Nie są oznaczone jako
wynik generatora ani dowód przejścia testów.

Przed uploadem: doprecyzować opis składni filtrów jako obsługiwany podzbiór,
a rozmycie w porównaniach przed/po oznaczyć jako redakcję lub zastąpić
rzeczywistymi przechwyceniami. Finalne zrzuty aktualnej paczki wymagają
uruchomienia Playwright; zobacz ../screenshots.md.
