**Full description — 1841 characters**

```text
Apex AdBlocker helps reduce ads and tracking while you browse with Google Chrome. It uses filter lists bundled with the extension and performs filtering locally in your browser.

Key features:
• Block advertising and tracking requests using built-in filter lists.
• Hide advertising elements on websites.
• Enable or disable protection for a selected domain and its subdomains.
• Optionally reload the tab after changing protection.
• Use the element picker to create your own cosmetic filters.
• Edit custom filters and import or export settings to a local file.
• View local engine diagnostics and YouTube player status.
• Use light and dark appearances that follow your system preferences.

Free, with no account required
Apex AdBlocker is free and has no paid protection tier or subscription. A single built-in set of lists covers advertising, tracking and known threats.

Local operation
The extension processes page addresses and elements inside your browser to apply filters. Settings and diagnostics are kept locally. Apex AdBlocker has no developer-operated backend and does not send telemetry to its author. Sharing a diagnostic report is a manual action using the copy button.

Limitations
Results depend on filter lists, website changes and Chrome's restrictions. The extension may not block every advertisement or tracking mechanism. Some sites may detect ad blocking. Apex AdBlocker does not replace antivirus software or your own assessment of a website's trustworthiness.

If a site stops working correctly, open the Apex AdBlocker popup and disable protection for that site. You can also inspect diagnostics in settings.

The interface is available in English and Polish, selected automatically from the browser language.

Apex AdBlocker is an independent project and is not affiliated with Google, YouTube or uBlock Origin.
```
